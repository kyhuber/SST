Privacy Policy

HPIC Financial Snapshot · Last updated 14 August 2026

HPIC Financial Snapshot is an internal dashboard used by the board of the Highland Park Improvement Club (HPIC), a volunteer-run nonprofit in Seattle, Washington. It shows the organization's own financial position in one place. It is not a public website, not a commercial product, and is not offered to anyone outside HPIC.

What data the tool accesses

The tool reads HPIC's own records from services HPIC already uses:

  • QuickBooks Online — current balances of specific HPIC bank accounts, read through the QuickBooks Online Accounting API.
  • Little Green Light — HPIC's grant records, including amounts applied for, awarded, received, and outstanding. (Planned; not yet enabled.)

It accesses only HPIC's own organizational data. It does not access data belonging to any other QuickBooks company.

The tool is read-only

The tool never creates, modifies, or deletes anything in QuickBooks Online, Little Green Light, or any bank. It only reads. It does not move money and cannot initiate any transaction.

Personal information

The tool is not designed to collect or display personal information. It reads account balances and grant totals, not individual donor records, and it does not build profiles of any person. It does not use cookies, analytics, advertising, or third-party trackers of any kind.

How data is handled

  • Financial figures are fetched on demand and held briefly in server memory. A short-lived cache (approximately fifteen minutes) exists so the dashboard does not call QuickBooks on every page load.
  • Authorization tokens for QuickBooks Online are stored server-side, encrypted at rest by the hosting provider, and are never sent to the browser.
  • No financial data is stored in the web page itself, in the public code repository, or in any database or spreadsheet.
  • Access requires a shared passphrase known only to authorized HPIC board members.

Who data is shared with

No one. HPIC's data is not sold, rented, shared, or disclosed to any third party. It is not used for marketing, aggregated into any dataset, or used to derive insights across organizations. The only parties involved are HPIC and the service providers HPIC has already chosen: Intuit (QuickBooks Online), Little Green Light, Cloudflare (hosting), and GitHub (hosting the static page).

Disconnecting

An HPIC administrator can revoke the tool's access at any time from within QuickBooks Online, under Apps → My Apps → Disconnect. Access ends immediately, and the dashboard will show that it is no longer connected. Stored authorization tokens become invalid at that point.

Contact
